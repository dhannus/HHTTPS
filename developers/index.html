Mit nachgewiesener Menschlichkeit bauen.
Ohne Menschen zu speichern.

HHTTPS ist ein offenes Internet-Protokoll — der Nachfolger von HTTPS — mit dem deine Plattform Menschen von Maschinen unterscheiden kann, mittels kryptografischer Zero-Knowledge-Beweise. Keine Konten. Keine PII. Keine Tracking-IDs. Nur ein verifizierbares Signal, dass am anderen Ende ein echter Mensch sitzt.

[ 01 ]

Anonymes Mensch-Label

Ein kurzlebiges ES256 JWT beweist is_human: true, ohne zu verraten wer. Verschiedene Plattformen erhalten verschiedene Pseudonyme — null Cross-Site-Tracking.

[ 02 ]

Registrierte Maschinen

KI-Anbieter signieren ihre Anfragen mit einem Machine-Token. Haftung liegt damit beim Betreiber — nicht bei jedem Menschen, der täglich beweisen muss kein Bot zu sein.

[ 03 ]

Standardmäßig offen

IETF Internet-Draft, EUPL-1.2 Referenz-Implementierung, föderiertes Issuer-Modell. Kein Vendor-Lock-in, kein zentraler Kontrollpunkt.

Integration

Drei Zeilen, ein Header.

Pack das SDK in deine Express-, Django- oder Flask-App. Verifiziere den HHTTPS-Token Header bei jedem Request, bekomm einen geparsten Identitäts-Claim zurück, entscheide was du damit tust. Webhooks (HMAC-SHA256) informieren dich, wenn Tokens widerrufen werden.

  • → sdk/client.js für Node / Express
  • → sdk/client.py für Django / Flask
  • → JWKS-Rotation wird automatisch gehandhabt
  • → Rate-Limiting & Webhook-Retry eingebaut
verify.js 
// 1. Install
$ npm install @hhttps/client

// 2. Verify on every request
import { verifyToken } from '@hhttps/client';

app.use(async (req, res, next) => {
  const token = req.headers['hhttps-token'];
  req.hhttps = await verifyToken(token);
  // → { is_human: true, role: 'citizen', ... }
  next();
});
